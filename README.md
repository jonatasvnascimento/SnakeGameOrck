# SnakeGameOrck

Jogo da cobrinha feito com React, Vite e TypeScript.

## Pré-requisito

- Node.js 20 ou mais recente.

## Iniciar o projeto

Na raiz do repositório, instale as dependências na primeira vez:

```bash
npm install
```

Depois, inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Abra o endereço exibido no terminal — normalmente `http://localhost:5173`.
Use as setas do teclado para controlar a cobra.

## Gerar a versão de produção

```bash
npm run build
```

Os arquivos prontos para publicação são gerados em `dist/`.

## Visualizar a versão de produção

Depois do build:

```bash
npm run preview
```
